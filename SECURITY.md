# Security Policy

## Supported Versions


| Version | Supported          |
| ------- | ------------------ |
| 5.x.x   | :white_check_mark: |
| <= 4.x  | :x: |


## Reporting a Vulnerability

Please use the issue system to report any minor defects or questions.

Any major vulnerabilities or critical issues should be disclosed to one or more maintainers directly via email.
